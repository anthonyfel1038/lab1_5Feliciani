# lab1_5Feliciani — Motorcycle Java Project

CMPSC 221 Lab 1.5. Demonstrates Java object-oriented programming, constructors, encapsulation, getters/setters, and composition through Motorcycle, Engine, Transmission, Wheel, and Brake classes.

## Run
Open the folder as a Java project in IntelliJ IDEA with JDK 21, then run `src/Main.java`.

Or run from the project root:

```bash
javac -d out src/*.java
java -cp out Main
```

## Requirements
- Three motorcycle objects created using constructors.
- Every instance field has a getter and setter.
- All motorcycle details printed using getters.
- Each Java file includes the required documentation header.
